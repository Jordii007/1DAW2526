# 1ºDAW 

Este repositorio contiene una recopilación estructurada de materiales, resúmenes teóricos y ejercicios prácticos correspondientes al primer año del Ciclo Formativo de Grado Superior en **Desarrollo de Aplicaciones Web (DAW)**.

El contenido está enfocado principalmente en dos pilares fundamentales del desarrollo: la **Programación Orientada a Objetos (POO)** y la gestión de **Bases de Datos Relacionales (SQL y PL/SQL)**.

## 🚀 Contenido del Repositorio

### 💻 Programación (Java / POO)
Recursos centrados en el paradigma de Programación Orientada a Objetos, con ejemplos prácticos y resolución de problemas comunes.
* **Fundamentos de POO:** Clases, objetos, constructores y métodos.
* **Pilares de la POO:** Encapsulamiento, herencia, polimorfismo y abstracción.
* **Estructuras de Datos:** Manejo de Arrays, Listas (ArrayList), Conjuntos y Mapas.
* **Manejo de Excepciones:** Bloques try-catch, creación de excepciones personalizadas.
* **Interfaces y Clases Abstractas:** Diseño de contratos y jerarquías complejas.
* **Persistencia de Datos:** Lectura y escritura de ficheros y serialización de objetos.

### 🗄️ Bases de Datos (SQL & PL/SQL)
Material detallado sobre el diseño, implementación y manipulación de bases de datos relacionales, utilizando estándares de la industria.
* **Lenguaje de Definición de Datos (DDL):** `CREATE`, `ALTER`, `DROP` y gestión de restricciones (Constraints).
* **Lenguaje de Manipulación de Datos (DML):** Consultas avanzadas, `JOINs`, subconsultas y funciones de agregado.
* **PL/SQL Procedimental:**
    * Bloques anónimos, estructuras de control (bucles y condicionales).
    * Gestión de cursores implícitos y explícitos.
    * Creación de Procedimientos, Funciones y Triggers.
