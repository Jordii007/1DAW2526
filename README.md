# Programación Orientada a Objetos (POO) • Prácticas
¡Bienvenido/a a este repositorio! Aquí iré recopilando todas las prácticas, ejercicios y proyectos desarrollados durante el aprendizaje de la Programación Orientada a Objetos (POO).

El objetivo de este espacio es asentar las bases del desarrollo de software estructurado, limpio y reutilizable, aplicando los pilares fundamentales del paradigma de objetos.
